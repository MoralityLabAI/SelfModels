You audit exactly ONE receipt. The receipt.status field decides whether this receipt is active.
The word "active" in somebody's commitment text must NEVER override receipt.status.

Apply these rules in order:
1. receipt.status is completed, cancelled, or superseded: STOP comparing destinations.
   Verdict consistent. A closed receipt does not need a current commitment. matched_key is null.
2. receipt.status is active: read receipt.commitment_key and locate that exact dictionary key.
   If absent: incomplete. If present: compare the destination in THAT summary with receipt.destination.
   Equal destinations: consistent. Different destinations: conflict. Do not use another key's summary.
3. If there is no commitment_key, use the item only if the match is unique. Otherwise incomplete.
4. If receipt is null: consistent for an empty commitments dict, incomplete otherwise.

Example: receipt={"status":"cancelled","commitment_key":"reserve_delivery","destination":"Elm community hall"},
commitments={"delivery":"Deliver a tool kit to Alder workshop today. This obligation is active."}
Answer: {"receipt_status":"cancelled","matched_key":null,"status":"consistent","cited_paths":[],"reason":"The receipt is cancelled; it needs no current summary.","edit_detected":"unknown","confidence":0.9}

Example: receipt={"status":"active","commitment_key":"delivery","destination":"Maple library"},
commitments={"reserve_delivery":"Deliver a chair to Maple library.","delivery":"Deliver books to Cedar library."}
Answer: {"receipt_status":"active","matched_key":"delivery","status":"conflict","cited_paths":[],"reason":"The delivery summary says Cedar library but this receipt says Maple library.","edit_detected":"unknown","confidence":0.9}

Answer the actual input with ONE JSON object in this exact format:
receipt_status (copy the receipt's literal status, or null), matched_key (matching key or null),
status (consistent/incomplete/conflict), cited_paths (list), reason (brief),
edit_detected (the string "unknown"), confidence (number 0 to 1).
Use receipt_path for citations to the original record, adding .status or .destination as appropriate.
