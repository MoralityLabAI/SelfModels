# ASM-02: a self-model with bounded memory at every update

On the same ASM-01 population, the best deterministic two-state controller
achieves **678 successful decisions out of 800**. Its retained state occupies
one bit. The largest robust-certificate count among controllers with that
reward is **10 out of 800**. The complete observed-history ceiling is 695
successful decisions and 519 certificates.

These are exact counts on the fixed development fixture. A feasibility run
exposed the 678 reward and frontier size before `PROTOCOL.json` was written.
The protocol records that history and sets `prospective=false` and
`heldout=false`. The final synthesis adds a causal controller witness and
maximizes certificate coverage among reward-optimal policies. It uses the
same cases throughout.

## What the actor receives

The source is [ASM-01 at the pinned default-branch commit](https://github.com/MoralityLabAI/SelfModels/tree/e2019ea2077b9dacffa3dbc68999bf7477ad79bf/research/arithmetic_self_models).
There are 50 equally weighted initial episodes under the two existing
arithmetic regimes and 16 public phases. Both source files are checked against
SHA-256 before import. The successful reset remains seed 7 for regime 5 and
seed 15 for regime 49.

At phase `t`, the actor updates

\[
m_{t+1}=U_t(m_t,b_t),\qquad a_t=A_t(m_{t+1}),\quad m_t\in\{0,\ldots,K-1\}.
\]

Here `b_t` is the newly acquired bit and `t` is public. `observe()` accepts
exactly the controller, previous code, new bit and phase. `act()` receives
the updated code and phase. The fixed transition and action tables are
public compiled model storage; their size is outside the charged dynamic
state. Thus the result concerns retained state for this known finite task.

The evaluator holds the regime, arithmetic state and complete diagnostic
tape. Each reset is evaluated counterfactually and leaves that tape intact.
Reward stays inside the evaluator. This unchanged-tape condition is needed
for the dynamic program below. An enacted reset experiment would need a
different transition model and a new search.

The two-state optimum captures 278 of the 295 successes available above the
one-state baseline, or `278/295` of that observed-history opportunity. Its
absolute reward is 84.75%. The ceiling is 86.875%.

Certificate coverage answers a separate question. A certificate exists for
an episode and phase when the selected reset succeeds under every original
episode compatible with that phase and retained code. The compiled one-bit
policy has a pure cell covering ten decisions at phase 3; every other
occupied cell mixes regimes. Maximizing reward can retain evidence that
chooses a good action while leaving several hidden explanations compatible.
The last-eight-bit controller reaches the entire-history reward and still
leaves 134 certificates unavailable. A downstream self-model experiment
should keep both endpoints.

`summary.json` contains exact values, phase counts, controller hashes and
search sizes. `controllers.json` contains the K=1 and K=2 witnesses. The
larger controllers are regenerated by their explicit window or count rules.
Their global minimum capacity has not been solved here.

Unused states can be added to a valid controller without changing its
behavior. Therefore the four-state reward optimum lies in `[678, 695]`,
using the compiled two-state witness for its lower bound. For capacities
16 and 17, the four-bit window gives the tighter interval `[689, 695]`.
The eight-bit window reaches the ceiling, which proves a reward optimum
of 695 at capacity 256. Certificate optimality at these larger capacities
remains open in this port.

## Why the two-state search is exhaustive

A current partition records which of the fifty initial episodes carry each
retained code. State names are interchangeable at every public phase. We
choose state 0 for the cell containing episode 0 and represent state 1 by a
50-bit membership mask.

When the next observation arrives, there are at most four nonempty cells:
each previous state paired with bit 0 or bit 1. A deterministic causal
update assigns each entire cell to one new state. The search enumerates
every assignment, using the episode-0 cell to fix label symmetry. Empty
cells receive an arbitrary zero transition because their choice has no
effect on this population.

At a resulting partition, the best action in each cell selects the more
numerous regime. Ties select seed 7. The reward contribution is the sum of
the larger regime counts; a pure cell contributes all its members to the
certificate count. The dynamic program retains the best **cumulative**
`(reward, certificates)` pair for each identical current partition.
Future observations, compatible episode counts and available updates depend
only on that partition and public phase. Consequently a discarded path
cannot improve a later optimum.

The implementation encodes this lexicographic objective as
`reward * 801 + certificates`. Across all 800 decisions the certificate
count is at most 800. The path stores a four-bit transition rule per phase,
which is reconstructed into a controller and replayed independently.

The reachable partition counts, including the initial partition, are:

```text
1, 2, 8, 44, 260, 1310, 4886, 15872, 44978, 114068,
239510, 456178, 724380, 772690, 804432, 820712, 830416
```

The hard frontier cap is one million. Exceeding it raises an exception
before an optimality result can be emitted. K=1 follows directly from the
equal regime prior at each phase. Larger capacities receive explicit
constructive scores with the complete-history ceiling as an upper bound.

## Relation to MIC-18

The accompanying `mic18_core.py` preserves the exact EvalMath source bytes
and Apache-2.0 license. `PROVENANCE.json` records its origin and digest.
It supplies a separate interface check: for a uniform three-bit word with a
coordinate query disclosed after memory commitment, a causal two-state
controller scores `17/24`; a parity accumulator scores `1` using two states.
Those checks establish the common streaming convention. Their rewards are
reported in a separate summary field.

ASM-02 uses its own objective because it evaluates a reset at every phase
of the arithmetic tape. Its compiler receives the known finite prior during
offline synthesis. The deployed witness carries one bit from step to step.
Generalization to other laws, initial-state populations or drift requires
new development families and independent held-out evaluation.

## Reproduce

Python 3.11 or newer, standard library only, from repository root:

```sh
python -m unittest discover -s research/arithmetic_self_models/online_memory -p 'test_*.py' -v
python research/arithmetic_self_models/online_memory/asm02.py --check
python research/arithmetic_self_models/online_memory/audit_asm02.py
python research/arithmetic_self_models/asm01.py --check
```

The unit suite compares the canonical search with independent enumeration
of all labeled transition tables on three phases, reproduces the original
control totals and exercises the runtime input boundary. The full receipt
check redoes every phase of the two-state search and replays its witness.
The separate audit enumerates 335,872 complete transition-and-action
programs across nineteen small cases, checks eighteen episode-order
permutations and replays both committed witnesses through the original
ASM-01 reset semantics. It checks the search on bounded exhaustive cases
and reviews the full-search argument; `asm02.py --check` carries out the
complete 830,416-partition calculation.
The dedicated workflow has an eight-minute CPU limit. This port runs no
learner or native model and changes no evaluation split.
